# retrieval-reranker-port — RerankerPort + over-fetch so precision@k reaches ≥ 0.15

Raise retrieval `precision@k` from 0.0478 to ≥ 0.15 by adding a deterministic
`RerankerPort` (cross-encoder) over an over-fetched candidate pool, without regressing
generation faithfulness (0.792) or entity-resolution F1 (0.6410).

Branch: `feat/retrieval-reranker-port` (from `main`). Source audit: the Part A/B decision
document authored in this same session (read-only); findings mirrored in Engram
`reranker-port-audit-findings`.
